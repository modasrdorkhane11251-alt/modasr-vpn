## معرفی

مدثر بات یک موتور فروش end-to-end برای سرویس‌های مبتنی بر پنل (مرزبان و مشابهات) است. چرخه کامل فروش — نمایش پلن، انتخاب لوکیشن، پرداخت، ساخت اکانت روی پنل، و تحویل کانفیگ — بدون هیچ دخالت انسانی انجام می‌شود.

طراحی سیستم بر سه اصل استوار است:

1. **یک دیتابیس، هر تعداد رابط** — کاربرِ روبیکا و کاربرِ تلگرام روی همان جداول کار می‌کنند؛ سرویس خریداری‌شده در یک پلتفرم، در بقیه هم قابل مدیریت است.
2. **جداسازی کامل لایه انتقال** — منطق کسب‌وکار هیچ‌وقت مستقیماً با API پیام‌رسان حرف نمی‌زند؛ یک لایه انتزاعی (`platform/`) درخواست‌ها را به هر پیام‌رسان ترجمه می‌کند.
3. **قابلیت بهره‌برداری واقعی** — کرون‌های پایش، بکاپ خودکار، گزارش‌دهی ساخت‌یافته و نصب یک‌دستوری؛ نه فقط یک اسکریپت.

## امکانات

### فروش
- کاتالوگ محصول با دسته‌بندی، لوکیشن، حجم و مدت قابل‌تنظیم
- اکانت تست، تمدید با یک دکمه، افزایش حجم، لینک سابسکریپشن
- قیمت‌گذاری جداگانه برای کاربر عادی، نماینده و نماینده پیشرفته
- سفارش دستی ادمین، کد تخفیف، فروش حجم دلخواه

### مالی
- کیف پول داخلی با شارژ از هر پلتفرم
- کارت به کارت با صف تأیید رسید — **عکس رسید حتی از روبیکا به تلگرام ادمین می‌رسد**
- درگاه‌های آنلاین (زرین‌پال و سایر) از تنظیمات فروشگاه
- گزارش مالی، تسویه پورسانت نمایندگان

### بهره‌برداری
- گروه گزارشات تاپیک‌دار با **۱۰ تاپیک خودکار** و برچسب پلتفرم هر رویداد
- پایش سلامت پنل، هشدار اتمام حجم/زمان، بکاپ شبانه دیتابیس
- پنل تحت وب مدیریت + مینی‌اپ داخل تلگرام
- نصاب خودکار با ثبت و اعتبارسنجی وب‌هوک هر سه پلتفرم

## نصب

```bash
bash <(curl -Ls https://raw.githubusercontent.com/modasrdorkhane11251-alt/modasr-vpn/main/install.sh)
```

نصاب به‌صورت تعاملی موارد زیر را می‌گیرد و همه‌چیز را خودکار انجام می‌دهد:

1. **دامنه** — رکورد A باید از قبل به سرور اشاره کند؛ گواهی TLS خودکار صادر می‌شود.
2. **توکن بات تلگرام** — از `@BotFather`.
3. **توکن بله و روبیکا** (اختیاری) — هر کدام را ندهید، همان پلتفرم غیرفعال می‌ماند.
4. **شناسه ادمین** — برای دسترسی به `/panel`.

در پایان، وب‌هوک تلگرام و بله و هر دو endpoint روبیکا (`ReceiveUpdate` + `ReceiveInlineMessage`) ثبت و پاسخ‌شان اعتبارسنجی می‌شود. دستور مدیریت سرور هم به‌صورت `modasr` در دسترس قرار می‌گیرد.

```bash
modasr install    # نصب / نصب مجدد
modasr backup     # بکاپ دیتابیس و ارسال به ادمین
modasr update     # به‌روزرسانی از مخزن
```

```php
    'rubika'   => '...',
];

```

## لایه چندپلتفرمه

هر آپدیت ورودی پیش از رسیدن به هسته، به ساختار استاندارد تلگرام نرمال می‌شود:

- **بله** — API سازگار با تلگرام؛ عبور مستقیم.
- **روبیکا** — ترجمه کامل: پیام متنی، دکمه شیشه‌ای (button_id → callback_data)، فایل/عکس (`file` → photo/document با لینک دانلود CDN)، شناسه‌های GUID (`u0…` → `b0…` با نگاشت پایدار)، و ویرایش پیام به‌سبک قابل‌اعتماد (حذف + ارسال مجدد برای غلبه بر کش کلاینت).

ستون `platform` در جدول کاربران تعیین می‌کند پاسخ‌ها و اعلان‌های کرون به کدام پیام‌رسان بروند.

## گروه گزارشات تاپیک‌دار

1. یک سوپرگروه تلگرام با **Topics** بسازید و بات را ادمین کنید.
2. در بات: `/panel` ← «📣 گزارشات ربات» ← «انتخاب گروه گزارشات» ← شناسه گروه.
3. بات به‌طور خودکار ۱۰ تاپیک می‌سازد: خرید، پرداخت، خطا، اکانت تست، پورسانت، گزارش شبانه، کرون، بکاپ و…

هر گزارش با برچسب پلتفرم مبدأ می‌آید: `📱 پلتفرم: تلگرام | بله | روبیکا`

## پرداخت

| روش | توضیح |
|---|---|
| کارت به کارت | ارسال عکس رسید ← تأیید/رد ادمین ← تحویل خودکار سرویس |
| کیف پول | شارژ از هر پلتفرم، خرج در همه؛ موجودی واحد |
| درگاه آنلاین | زرین‌پال و سایر درگاه‌ها از تنظیمات فروشگاه |

## کرون‌ها

نصاب کرون‌های لازم را ثبت می‌کند؛ وضعیت‌شان از `/panel` ← «⏱ وضعیت کرون‌ها» قابل مشاهده است:

- هشدار اتمام حجم و زمان سرویس‌ها
- پایش سلامت پنل‌ها و ظرفیت فروش
- بکاپ شبانه دیتابیس و ارسال به تاپیک بکاپ
- پردازش صف رسیدها و اعلان‌های معوق

## ساختار پروژه

```
modasr-vpn/
├── index.php            # هسته بات — فلوهای کاربر
├── admin.php            # پنل مدیریت داخل بات
├── botapi.php           # لایه API + روتینگ خروجی پلتفرم‌ها
├── platform/            # انتزاع چندپلتفرمه
│   ├── platform.php     #   تشخیص پلتفرم، روتینگ، گزارشات
│   ├── BaleClient.php   #   کلاینت بله
│   └── RubikaClient.php #   کلاینت روبیکا + نرمال‌ساز آپدیت
├── panels/              # درایورهای پنل سرویس
├── cronbot/             # زمان‌بند و جاب‌های کرون
├── lang/                # fa · en · ru · zh
├── panel/               # پنل تحت وب
├── app/                 # مینی‌اپ تلگرام
└── install.sh           # نصاب + ابزار مدیریت سرور
```

## امنیت

- توکن‌ها فقط در `config.php` روی سرور؛ مخزن کاملاً بدون secret است.
- اعتبارسنجی IP وب‌هوک تلگرام با پشتیبانی Cloudflare (`CF-Connecting-IP`).
- امضای مخفی (webhook secret) برای وب‌هوک تلگرام.
- در صورت افشای هر توکن: revoke و سپس به‌روزرسانی `config.php`.
