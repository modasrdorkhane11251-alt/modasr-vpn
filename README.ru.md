## Обзор

MODASR Bot — это сквозной движок продаж для подписочных сервисов на базе панелей (Marzban и совместимые). Полный цикл продажи — выбор плана, выбор локации, оплата, автоматическое создание аккаунта на панели и выдача конфига — работает без участия человека.

Принципы архитектуры:

1. **Одна база — любое число интерфейсов** — пользователь Rubika и пользователь Telegram работают с одними таблицами; услуга, купленная в одной платформе, управляется и в остальных.
2. **Полная абстракция транспорта** — бизнес-логика никогда не обращается к API мессенджера напрямую; слой `platform/` транслирует каждый запрос.
3. **Реальная эксплуатационная готовность** — мониторинг через cron, автоматические бэкапы, структурированные отчёты и установка одной командой.

## Архитектура

```
  Входящий вебхук (index.php?platform=telegram|bale|rubika)
                        │
   Слой нормализации (platform/) → стандартная форма Telegram-апдейта
                        │
        Ядро бизнес-логики (index.php / admin.php)
                        │
      ┌─────────────────┼──────────────────┐
      │                 │                  │
  MySQL (общая)   Драйверы панелей   Движок отчётов
                  (Marzban, …)      (топики Telegram)
```

Исходящие сообщения маршрутизируются по платформе пользователя; административные отчёты всегда уходят в Telegram независимо от источника события.

## Возможности

- **Продажи** — каталог с категориями, локациями, тарифами по трафику и сроку, тестовые аккаунты, продление в один тап, ссылки подписки, цены по уровням (пользователь / агент / про-агент), промокоды
- **Финансы** — встроенный кошелёк, общий для всех платформ; перевод на карту с очередью проверки чеков (фото чека пересылается даже из Rubika админу в Telegram); онлайн-шлюзы (ZarinPal и др.); расчёт комиссий агентов
- **Эксплуатация** — группа отчётов с топиками: **10 автоматически создаваемых топиков** и метка платформы у каждого события; мониторинг здоровья панелей; предупреждения об окончании; ночные бэкапы БД; веб-панель администратора; мини-приложение Telegram

## Установка

```bash
bash <(curl -Ls https://raw.githubusercontent.com/modasrdorkhane11251-alt/modasr-vpn/main/install.sh)
```

Установщик интерактивно запросит домен, токены ботов (Telegram — обязателен; Bale/Rubika — опционально) и ID администратора, затем выпустит TLS-сертификат, зарегистрирует и проверит все вебхуки (включая оба endpoint'а Rubika) и установит команду управления сервером `modasr`:

```bash
modasr install    # установка / переустановка
modasr backup     # бэкап БД администратору
modasr update     # обновление из репозитория
```

## Конфигурация

`config.php` хранится только на сервере; в репозитории — плейсхолдеры:

```php
$APIKEY = '...';                 // основной токен бота
$PLATFORM_TOKENS = [
    'telegram' => '...',
    'bale'     => '...',
    'rubika'   => '...',
];
$REPORTS_BOT_TOKEN = '...';      // бот отчётов (по умолчанию — токен Telegram)
```

## Мультиплатформенный слой

Каждый входящий апдейт нормализуется к стандартной форме Telegram до попадания в ядро:

- **Bale** — API, совместимый с Telegram; прямая передача.
- **Rubika** — полная трансляция: текстовые сообщения, инлайн-клавиатуры (button_id → callback_data), вложения (`file` → photo/document с разрешёнными CDN-ссылками), отображение GUID (`u0…` → `b0…` с постоянным кэшем), надёжное редактирование сообщений (удаление + повторная отправка из-за клиентского кэша клавиатур Rubika).

Столбец `platform` у каждого пользователя определяет маршрутизацию ответов и cron-уведомлений.

## Группа отчётов с топиками

1. Создайте супергруппу Telegram с включёнными **топиками**; сделайте бота админом.
2. В боте: `/panel` → «📣 Отчёты» → «Выбрать группу отчётов» → отправьте ID группы.
3. Бот автоматически создаст 10 топиков: покупки, платежи, ошибки, тестовые аккаунты, комиссии, ночные отчёты, cron, бэкапы и другие.

Каждый отчёт содержит метку источника: `📱 Платформа: Telegram | Bale | Rubika`


## Безопасность

- Токены хранятся только в серверном `config.php`; репозиторий не содержит секретов.
- Проверка IP вебхука Telegram с поддержкой Cloudflare (`CF-Connecting-IP`) и секретом вебхука.
- При утечке любого токена: отзовите его и обновите `config.php`.

## Диагностика

| Симптом | Причина | Решение |
|---|---|---|
| Rubika не отвечает | endpoint не зарегистрирован | повторить `modasr install` |
| Устаревшие кнопки Rubika | клиентский кэш | встроенное поведение удаления/отправки — держите код обновлённым |
| Медленное оформление | панель сервиса офлайн | проверить здоровье панели |
| Вебхук Telegram отклонён | IP/proxy | проверить `getWebhookInfo` и настройки Cloudflare |
